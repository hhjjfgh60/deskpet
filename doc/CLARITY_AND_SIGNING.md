## 核查结论

源图为 `1536×2288` RGBA PNG，8列11行，每格 `192×208`。57个动作帧、16个方向姿态以及透明背景保持原样。上一版成功构建的实际素材校验已通过。

悬浮窗原本直接读取 `spritesheet.png`，不是宠物列表的 `thumb_atlas_v2.png`；未发现主动降采样或重复密度乘算。旧逻辑的尺寸为“帧像素×保存的 scale”，先用 `toDp()` 给 Compose 布局，再按整数目标像素绘图。这意味着100%是192×208**物理像素**，不是192×208 dp。

| 比例 | 显示像素（含原图透明留白） | 建议 |
| --- | --- | --- |
| 50% | 96×104 | 小尺寸 |
| 75% | 144×156 | 推荐稍小显示 |
| 100% | 192×208 | 推荐；逐像素原图 |
| 150% | 288×312 | 插值放大，不增加细节 |
| 200% | 384×416 | 超出源分辨率 |
| 300% | 576×624 | 明显超出源分辨率 |

当前手机的 scale 和屏幕密度不能从云端直接读取；没有假称测得你的手机值。新界面会在桌宠开启时显示**悬浮窗实测**宽高、实际解码帧宽高和 px/dp。未开启时只显示预计值。例如屏幕密度3 px/dp时，100%在布局中约为64×69.33 dp，绘图仍是192×208物理像素。

白发、眼睛等细节受单帧192×208上限约束；1536×2288是整张图集尺寸，不能作为单个角色分辨率。新版本不是用插值放大冒充高清。

## 本次修改

- PNG和回退解码都显式 `inSampleSize=1`、`inScaled=false`、ARGB_8888、Bitmap.DENSITY_NONE，避免隐式密度缩放，保持透明通道。
- 原生等尺寸采用逐像素绘图；缩小采用适当采样；放大仍说明其细节上限。
- 新增75%按钮，100%标为“原生”；不自动重置已保存的位置、scale或宠物选择。
- 原帧在工作线程预载，使用16MiB上限的LRU复用Bitmap；解码后的57帧约8.7MiB，避免每一轮重复解码PNG/分配临时Bitmap。更大导入素材不强行全量预载，仍有缓存上限。峰值预载时还需约13.4MiB原图缓冲。
- 缩放手势仅计算已知原生宽高，不再反复读图片文件。
- 播放采用单调时间轴，遇到延迟会赶上原始时间位置，避免逐帧累积滞后；状态切换仍从第一帧开始。
- 原始每帧时长完全保留。待机6帧总计1100ms，平均约5.45帧/秒；这不是60fps动画。消除额外解码停顿不会凭空生成新动作帧。
- 新增LRU复用/淘汰和播放时间边界/延迟追帧测试。

## 安装与签名

原始调试版 `com.deskpet` 的私钥没有保存，用户也没有另存。不能从APK恢复该私钥；第一次换成新固定签名时，需要先备份、再卸载旧调试版后安装。**当前保留旧版，不要提前卸载。**

已生成专用固定RSA签名，私钥和密码仅在用户可下载的私有文件中，未进入公开仓库。公开仓库仅保存证书SHA-256指纹 `signing-certificate.sha256`，它不包含私钥。

GitHub连接器不提供Secrets写入接口，也没有已登录GitHub的可用浏览器会话；需要用户在手机保存一次：

1. 下载对话提供的 `deskpet-signing-secret.json`，用文本查看器复制文件全文。该文件包含私钥与密码，请私下备份，不要提交到仓库或公开分享。
2. 打开 <https://github.com/hhjjfgh60/deskpet/settings/secrets/actions/new>。
3. Name填 `DESKPET_SIGNING_BUNDLE`，Secret粘贴JSON全文，点击 Add secret。
4. 打开Actions，选择 **Build GPT Dragon Android APK → Run workflow → main**。若之前因缺Secret失败，可以重新运行。

工作流先独立执行素材校验、测试及编译，然后加载Secret。Secret缺失时明确失败；不会用新随机调试密钥发布正式安装包。脚本在临时目录恢复私钥，校验证书指纹，遮蔽日志中的密码，用环境变量交给Gradle，最后清理私钥。私钥不会上传到artifact。

成功运行后，APK必须由固定证书签名才上传为 `gpt-dragon-android-apk`。报告artifact `android-validation-reports` 包含原生尺寸帧、打包PNG校验和、原版与新版签名比较。旧安装包artifact过期不阻断后续固定签名，但新证书校验始终强制执行。

当前版本 `versionCode=2`、`versionName=1.1-clarity`，applicationId继续为 `com.deskpet`。后续使用同一Secret、提高versionCode即可覆盖安装，保留现有DataStore和宠物文件。不要替换或删除Secret后生成新私钥；请妥善保留私有JSON备份。

## 第一次迁移：仅在固定签名构建成功后

1. 在**旧应用仍能运行时**，打开右上角“更多 → 备份全部”。把ZIP保存到下载目录或手机其他应用可见的位置，确认文件存在。
2. 下载新成功运行中的 `gpt-dragon-android-apk` 并解压。确认有 `app-debug.apk`，以及构建中的固定证书校验已通过。
3. 此时才卸载旧调试版，安装新版；允许悬浮窗、通知和后台运行权限。
4. 在新版中通过“导入 → 恢复备份”选择刚保存的ZIP。备份包含位置和scale；新版恢复对已存在的内置宠物也会恢复其设置，避免默认内置龙娘阻止恢复。
5. 点“100% 原生”或75%查看清晰效果；这一步是你主动选择新大小，不会在升级时悄悄覆盖旧设置。

一次迁移后，后续固定签名版本直接覆盖安装，不需重复卸载。
